Core Rules
1
Weigh every morning. Same conditions — post-toilet, pre-food.
2
Zone is determined by 7-day rolling average only. Single weigh-ins are noise.
3
Never exit a zone until the rolling average confirms it. Not how you feel.
4
Protein stays fixed at 195g at every zone. Carbs are the only lever.
Fitbit Morning Shortcut
Set up an iOS Shortcut to open this app each morning after your Fitbit sync. No API keys required.
1
Open the Shortcuts app on your iPhone.
2
Tap + → Add Action → search Open URL.
3
Set the URL to the address where this app is hosted (e.g. your GitHub Pages URL).
4
Tap the shortcut name → Add to Home Screen. Done.
5
Go to Automation tab → + → Time of Day → set 07:30 AM daily → add action: run this shortcut.
Install as iPhone App
Add this tracker to your home screen so it runs like a native app — no App Store needed.
1
Open this page in Safari (not Chrome).
2
Tap the Share icon at the bottom of Safari.
3
Scroll down and tap Add to Home Screen.
4
Rename it Protocol and tap Add. It will appear as a full-screen app.
Data Storage
All weight data is saved locally on your device using browser storage. It persists between sessions and works fully offline once installed.
